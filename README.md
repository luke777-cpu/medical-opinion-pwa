# 의학적 소견서 작성 도우미 v1

브라우저와 스마트폰에서 작동하는 PWA 초안입니다.

## 실행

정적 웹 서버로 `app` 폴더를 서비스합니다.

```bash
python3 -m http.server 8080 --directory app
```

브라우저에서 `http://localhost:8080`을 엽니다. 스마트폰 카메라 촬영과 PWA 설치는 HTTPS 배포 주소에서 사용하는 것을 권장합니다.

## 기본 흐름

1. 진료기록 촬영 또는 이미지 선택
2. 브라우저 내 OCR 실행
3. 의사가 원본과 대조하여 수정·승인
4. 환자 정보와 실제 치료 경과 입력
5. 실제 시행한 치료·약품 선택
6. 환자별 필요성 근거 입력
7. 소견서 생성, 최종 검토, 인쇄/PDF

## 안전 원칙

- OCR 결과는 자동 확정하지 않습니다.
- 치료의 효능이나 의학적 필요성을 치료명만으로 단정하지 않습니다.
- 선택한 치료에 일반적 설명만 제시하고, 환자별 필요성은 실제 기록에 근거해 의사가 입력합니다.
- 데이터는 기본적으로 해당 브라우저의 `localStorage`에만 저장됩니다.
- 공용 기기 사용을 피하고 사용 후 `환자 자료 초기화`를 실행하십시오.
- 현재 버전은 진료 보조용 초안 작성 도구이며, EMR 연동·사용자 인증·암호화 저장·감사로그는 포함하지 않습니다.

## 배포 전 필수 보완

- 병원 내부 보안정책에 맞는 인증, 세션 만료, 서버 측 암호화, 접근·수정 감사로그
- OCR 모델과 라이브러리의 자체 호스팅
- 검토된 약품 설명 DB와 버전 관리
- 환자 식별정보 최소화 및 보존기간 정책
- 의료진 사용자 테스트, 브라우저/Android 테스트, 개인정보 영향평가
